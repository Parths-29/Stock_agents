# Working on StockPaws

- Commit completed, validated milestones with clear commit messages. Keep backend, interface, and documentation milestones reviewable. Push to the configured repository when the user requests repository delivery.
- Keep the README professional and current: include real screenshots, setup instructions, current capabilities, architecture, and each companion's actual role.
- Do not commit secrets, database files, session tokens, generated test state, or private wallet keys.
- Never fabricate TEE attestations, live-data status, transaction hashes, explorer links, or provider verification.
- Price, risk, and fill calculations belong on the server; AI may explain them. All executions currently use virtual funds.
- Run the relevant tests, TypeScript check and production build for material changes. Exercise changed browser flows and update screenshots when the interface changes.
